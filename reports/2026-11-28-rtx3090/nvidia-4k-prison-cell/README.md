# RTX 3090 at Yolanda's table in the prison cell

The Series X run on the November 28 VIctory-NVIDIA branch presented **1,655 frames in 120 seconds, averaging 13.79 FPS** at 3840 × 2160 output. In the first minute the average was 12.23 FPS. In the second it was 15.35 FPS. The weakest five seconds contained 14 frames (2.8 FPS). No five-second window reached 25 FPS. The 95th percentile interval was 93.66 ms and the longest was 3.45 s. Lucia walked from the window to the cell door and then to the table before the timed interval. During the interval she stayed beside Yolanda and received interaction inputs. The attached pictures were captured outside the timed window. The table, clothing, wall texture and window mesh remain visible in both. Rectangular light patches remain by the door in this run and the introduction showed streaks across a face. The renderer uses the fork's approximate indirect lighting. Its host-pipeline reports recorded a median 337.5 omitted draws per frame. The run also omits work that requires the game's ray-tracing structures. The GPU utilization samples had a median of 97.5%. Peak sampled VRAM usage was 15,787 MiB and the minimum available system RAM was 4.07 GiB. The renderer had foreground focus. No Rust compiler ran during the timed window. Frame generation and DLSS were off. The test used the SSD-backed page pool on D and a 16 GiB process working-set ceiling. [GPU samples](gpu.csv)
