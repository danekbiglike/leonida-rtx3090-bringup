# RTX 3090 prison escort with the meshlet collection shader translated

Lucia followed the officer from A-102 into the dayroom. The renderer presented **2,048 frames in 120 seconds**, averaging **17.07 FPS** at Series X settings and 3840 × 2160 output. Five-second averages ranged from 13.6 to 20.0 FPS. The 95th-percentile interval was 82.12 ms and the longest was 156.43 ms. None of the 24 five-second intervals reached 25 FPS. There was at least 4.43 GiB of physical RAM available throughout the escort. [Frames](escort-frames.csv) · [Metrics](escort-metrics.json) · [Compared endpoints](compared-endpoints.jpg)

The previous 32-lane translation failure for `6b82bc7d22016cb5` did not recur in the run log. A probe set to report the first nonempty **direct** native dispatch recorded by this shader reported none. It did not monitor indirect dispatches. The [separate RTX 3090 hardware check](../rtx3090-triangle-collection-wave32) verified that the same input now produces a validated D3D12 compute pipeline. The dayroom still had dark figures against the barred doorway. We observed no visual improvement there that could be attributed to the shader. [Gate and dayroom images](escort-route.jpg)

The separate two-minute cell interval yielded 1,504 presents (12.53 FPS), with a 2.4 FPS five-second minimum, a 144.38 ms 95th percentile and a 1.646 s maximum interval. Lucia ended that interval near the curtain and sunlit wall; the earlier buffer-slot run ended with a wider view of the room. Those cell averages represent different workloads. [Cell frames](cell-frames.csv) · [Cell images](cell-route.jpg)

This run used [PR 822](https://github.com/trustno1-coder/VIctory-NVIDIA/pull/822) on the local renderer with an RTX 3090, Ryzen 7 3700X, 32 GiB system memory and SSD. Full GPU write declarations and the original directional light grid were enabled, with no DLSS or frame generation. The game exited normally after the benchmark.
