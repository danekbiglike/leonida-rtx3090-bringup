# RTX 3090 DLSS device test and a false positive in the game startup log

An RTX 3090 with driver 610.88 evaluated DLSS Quality on stand-in textures at 2560 × 1440 input and 3840 × 2160 output. In the restricted game launch with the same renderer and SDK, the startup console printed “DLSS on” before the device handover. NGX then returned 0xbad00002. The DLSS plugin reported a missing NGX context and the function lookup for slDLSSGetOptimalSettings failed. No in-game DLSS evaluation was observed. This run supplies no in-game DLSS frame rate.

The device tests used the renderer’s upscaler-check command with --output 3840x2160 --device. Super resolution was requested in Quality mode and frame generation was off. Each desktop test used a fresh private temporary folder. The minimal environment specified the Windows folder, System32 search path, private local and temporary paths and Streamline test settings. Adding ProgramData and SystemDrive let the desktop check evaluate on the GPU. Adding those same variables to the restricted game harness still produced a device initialization failure in a standalone check. The experiment does not identify the remaining failing dependency. The game harness retained its AppContainer, single-process job, CPU and memory limits. All six installed DLLs had valid NVIDIA Authenticode signatures.
