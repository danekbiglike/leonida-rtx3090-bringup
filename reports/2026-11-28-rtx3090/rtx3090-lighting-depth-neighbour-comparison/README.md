# Depth-neighbour reads for diffuse lighting on RTX 3090

The existing five direct depth loads were faster than two alternatives in this fixture. Both alternatives preserved the final pixels when they reused **raw depth**. At 3840 × 2160 the median paired cost of the diffuse resolve rose by **22.5 µs** with a 10 × 10 shared tile. Replacing the loads with two hardware texture gathers cost **20.5 µs** and **14.3 µs** in two runs. Running the reference shader against itself gave **1.0 µs** at the same resolution. The game candidate keeps its original depth loads. [Paired timings](diffuse-medians.csv)

Each run had seven alternating timed pairs on three scenes at 1297 × 733, 2560 × 1440 and 3840 × 2160. One scene exercises dim indirect light. The harness also ran the reflection pass as a control. Both variants used the same 16 × 2 light gather, the same 0.05 floor and the same 13 root constants. Both hardware-gather variants used the same fixed clamp sampler in their root signature. GPU timestamps enclose the resolve and its barrier. The fixture checked all output pixels and all 995,344 cell-buffer bytes. At 4K the diffuse image comparison covered 33,177,600 bytes per image. The tests ran outside the game while the next renderer was being compiled. An earlier attempt stored reconstructed 3D positions in group-shared memory. The first odd-sized scene had a pixel mismatch at offset 10,790 and the cell buffers also differed. It was rejected before collecting performance results. The two raw-depth alternatives preserve the original position arithmetic independently at each pixel.
