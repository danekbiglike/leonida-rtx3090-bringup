# Indexed buffer refreshes with the November 28 texture-streaming changes

The attached source patch applies to VIctory-NVIDIA commit `63b902fe1720a5188ee79d94a88c8de0470f6349`. On a Ryzen 7 3700X the resulting native Windows release passed **132 tests across ten focused suites**. Four tests were ignored. The release SHA-256 is `f7ffce0967cdb7a704be7f391d1629fa9853d05dc4cef62e2474d6d6dec8e25f`. These are build and correctness results. They supply no in-game FPS estimate.

The RTX 3090 integration records the existing shadow index on each refresh during the submission's first walk. A shader write can precede the first refresh of the same shadow. Its lookup is deferred until the index is complete. Replaying the resulting events into reusable vectors keeps the order of first use and the boundaries between parts. A differential test compares the produced ranges with the original algorithm across submissions of varying sizes. The parallel check for unchanged refreshes uses owned input storage that returns to the calling batch after the workers finish.

The upstream changes schedule fresh textures, avoid detiling known-zero mips, narrow the write-watch query and reduce descriptor and texture-pool lock contention. The patch also includes the upstream AVX2 comparison, the blend-shape warmup, and the local SSD page-pool and test-input support.
