# Grouping buffer refresh jobs on the RTX 3090 prison escort

The two-minute 4K escort from gate A-102 into the dayroom produced **2,032 presents, or 16.93 FPS**. The five-second averages ranged from **13.6 to 19.0 FPS**. The longest frame took **200 ms**. The earlier depth-audit run reached the same room with 2,114 presents (17.62 FPS), a 12.4 FPS minimum, and a 219 ms longest frame. Both starts show the A-102 door, Lucia and the officer, and both endpoints show the same group in the dayroom. The characters there still look like dark silhouettes. [Matched endpoints](compared-endpoints.jpg) · [Raw presents](escort-frames.csv) · [Prior run](../4k-prison-depth-and-write-audit)

In this experiment each worker can claim up to eight adjacent buffers at once when a front refresh batch exceeds 256 spans. Textures remain individually claimable. During complete reporting intervals on the escort the median was **4,859 buffers in 857 buffer jobs per frame**. The median elapsed time for front refreshes was **14.48 ms per frame**. The code also uses the small GPU buffer pools from the previous experiment; that build did not reach the gate, so this comparison does not isolate grouping. The grouped run does not improve the best mean, and an older ordered-upload run already held 13.6 FPS in its slowest five seconds. [Per-interval counters](front-refresh.csv) · [Scheduling and counters patch](front-refresh.patch) · [Pooled-only trial](../4k-file-backed-reads-prison-cell)

The separate 120-second interval beginning in the cell presented **1,532 frames (12.77 FPS)**. The slowest five seconds averaged 9.8 FPS, the fastest 14.4, and the longest frame took 649 ms. The cell movement and camera differed from earlier runs. [Cell metrics](cell-metrics.json) · [Cell presents](cell-frames.csv)

The test used a Ryzen 7 3700X, RTX 3090, 32 GiB system RAM, SSD, Series X profile, 3840 × 2160 output, frame generation and DLSS disabled. The renderer used the same 0.05 indirect-light minimum and preserved GPU write declarations. Seven targeted tests passed, including exact-once coverage for textures and buffer spans at four widths, ordered copies, and a 100,000-byte GPU readback.
