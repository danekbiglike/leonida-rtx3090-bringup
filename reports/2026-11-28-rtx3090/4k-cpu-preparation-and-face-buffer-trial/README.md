# RTX 3090 native 4K prison run with CPU preparation and half-buffer changes

The two-minute window in the cell presented 1,766 frames (14.72 FPS). The slowest five seconds averaged 12.2 FPS and the longest frame lasted 145 ms. The guard run presented 1,558 frames (12.98 FPS). Its first minute averaged 9.23 FPS and its second 16.73 FPS. The best five seconds averaged 19.4 FPS. One five-second window had no presents. The 25 FPS target remains open. Twelve full Windows thread-CPU samples overlap this interval. One unnamed emulator-process thread accumulated 12.359 CPU seconds in 12.425 wall seconds. Its stack and role were not captured. The measured build includes [CPU preparation PR 850](https://github.com/trustno1-coder/VIctory-NVIDIA/pull/850), head 8cb7a2fda21fcc499f40f76c93ca48c921939c8c, and [shader half-buffer PR 857](https://github.com/trustno1-coder/VIctory-NVIDIA/pull/857), head 9e41da6d7eb7aefadc09a1ec3e2aeb8ff85115e5. It preserves the two reflection resolve passes and the 4.5 GiB physical memory prefetch reserve. A separate shader and pipeline cache was initialized for the new shader representation. At least 5,000 reflection clamps ran. The unsigned-buffer hardware test returned all 65,536 bit patterns intact on this RTX 3090. The game produced no runtime message identifying the unsigned-view substitution, and the ending camera is behind Lucia. The stripe on her face remains unverified. Across 17 recorded test invocations there were 147 passes and three ignored tests.
