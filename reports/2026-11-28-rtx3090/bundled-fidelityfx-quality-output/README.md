# The bundled Xbox FidelityFX Quality path rejects a 4K output

The Series X run requested a two-thirds scene scale with a 3840 × 2160 output. The title loaded its own upscaler library and explicitly rejected the output size. It reported that its shipping FSR4 tables support a fixed 1920 × 1080 Quality output. The renderer exited with 0xc0000094 before playable frames. This test used VICTORY_FSR_PATH=1 with VICTORY_DLSS_MODE=quality. DLSS and frame generation were off. [Game diagnostic](nvidia-fsr-quality.json)

A separate native Series X 2560 × 1440 SDR run reached Lucia's cell and rendered the window, bunks and door. It subsequently stopped presenting and reported a null write. The last 30 seconds through the final present contained 91 frames while at least 3.70 GiB of physical memory was available. The viewpoint and the state of the pipeline cache changed over that short interval. There is no completed 120-second cell or corridor measurement for either of these profiles. [Native run](nvidia-1440.json)
