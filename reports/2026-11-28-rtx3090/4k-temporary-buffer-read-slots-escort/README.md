# RTX 3090 prison escort with temporary buffer read slots

The renderer presented **2,095 frames in 120 seconds (17.46 FPS)** while Lucia walked with the officer from A-102 into the dayroom. The slowest five seconds delivered 70 frames (14.0 FPS), the fastest delivered 97 (19.4 FPS), the 95th-percentile frame interval was 80.60 ms and the longest was 142.31 ms. None of the 24 five-second intervals reached 25 FPS. The [earlier best run](../4k-prison-depth-and-write-audit) averaged 17.62 FPS with a minimum of 12.4 FPS and a 75.93 ms 95th percentile. This run had a higher minimum and a lower average. Run-to-run variation and other differences between the builds prevent attributing the change to the slot lookup. [Frame intervals](escort-frames.csv) · [Metrics](escort-metrics.json) · [Matched boundary images](compared-endpoints.jpg)

The change uses temporary buffer offsets to select repeated reads while preserving their original order. During this escort the median reported rate of buffer fills was 5,325 per frame. Across complete thread sampling intervals covering 2,081 presents, the submission thread used 38.11 ms of CPU per present and the six recording threads used 139.59 ms combined. Windows had at least 4.68 GiB of available physical memory.
