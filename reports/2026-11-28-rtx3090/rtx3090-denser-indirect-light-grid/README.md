# A denser indirect-light grid on the RTX 3090

This test changes the spacing of the indirect-light estimate to investigate the [rectangular highlight around the prison wall light](../prison-wall-light-screen-grid). The reference samples 160 × 90 points; the alternative samples 192 × 108. Both use 16 × 2 threads, the same lighting equations, the same 0.05 minimum diffuse light, and the same output resolution. All shaders that read the point buffer, its allocation, and both gather dispatches use the selected size. The normal setting remains 160 × 90. [Renderer and hardware-test patch](fine-grid.patch)

Two independent D3D12 runs compared both grids at 1297 × 733, 2560 × 1440 and 3840 × 2160, across four generated scenes. Each grid reproduced its own output pixels and cell bytes in five alternating pairs per scene and resolution. Uniform incoming black light on a flat surface produced identical pixels and cell bytes on both grids. At 4K, changing the grid affected 1,174,002 of 8,294,400 diffuse pixels in the first varied scene and 3,980,698 in the second. In the dim scene the diffuse output stayed identical while the half-size reflection changed. Thus this switch changes the intended lighting inputs in a repeatable way. Its effect on the in-game wall artifact requires an in-game capture. [4K summary](4k-summary.csv)

On the first varied 4K scene, the diffuse gather took about 537 µs with the original grid and 492 µs with the finer grid. In the flat control the original took about 408 µs and the finer grid 490 µs. GPU timestamps cover dispatches and their UAV barriers; the readbacks are outside the timing window. The denser grid uses an extra 405,504 bytes for the point buffer. The test gives no in-game FPS result. [First run](hardware-grid.csv) · [Repeat](hardware-grid-repeat.csv)

The renderer's own hardware tests separately allocated both point buffers on the RTX 3090 and checked the resource size and exact dispatch coverage. To run the comparison fixture, build the C++17 source with MSVC and link d3d12.lib, dxgi.lib and d3dcompiler.lib. Pass the reference and patched ambient.rs file paths, then `16 fine-grid`. The fixture extracts their HLSL directly. [Fixture source](light_depth.cpp) · [D3D12 utilities](d3d_test.hpp)
