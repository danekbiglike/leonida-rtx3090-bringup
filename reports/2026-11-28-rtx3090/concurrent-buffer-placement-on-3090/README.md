# Concurrent CPU-buffer placement and GPU readback on RTX 3090

On a Ryzen 7 3700X and RTX 3090, creating 256 upload buffers of 64 KiB took **90.58 ms** as individual allocations and **1.16 ms** from a warm pool. For shared buffers the times were **108.57 ms** and **1.34 ms**. Each figure is the best of three fixture times. The pool had already created a block. These figures cover allocation and mapping in this fixture and make no prediction about FPS or cold heap creation. [Measurements](test-results.txt)

The local integration combines pooled upload and shared buffers with creating fresh heaps outside the shared pool lock. The new regression fills a synthetic 64 MiB block with supported allocations until 64 KiB remains. One thread asks for 4 MiB and waits inside the callback that creates a new heap. Before releasing it, the second thread obtains the last 64 KiB from the original heap. The test checks the exact offsets and heap identities. This covers the case where creating a large buffer would otherwise hold up an unrelated small request. On the hardware, a copy from a pooled upload buffer into a pooled shared buffer returned all **100,000 expected bytes**. Separate tests checked buffer contents after reuse, submission ordering and depth publication. Eleven selected tests passed.
