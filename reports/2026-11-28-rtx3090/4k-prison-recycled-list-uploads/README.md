# A 17.64-second stall on the RTX 3090 prison route

The command-list upload pool was active in this native 4K run. The cell interval presented 1,932 frames in 120 seconds (16.10 FPS), with no presents in its final five seconds. Lucia was still by the bookshelf in the end capture. Later, unscored captures show her in the hallway with the officer and in a dark room. The driver never confirmed the A-102 starting view, so this run has no comparable gate FPS result. The previous ordered-copy run reached the corridor during the cell interval and averaged 17.40 FPS in its separate gate test.
