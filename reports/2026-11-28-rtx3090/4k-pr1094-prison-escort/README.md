# RTX 3090 4K prison escort with the PR 1094 buffer refresh changes

The local integration of [PR 1094](https://github.com/trustno1-coder/VIctory-NVIDIA/pull/1094) presented 1,978 frames during the two-minute walk with the officer from A-102 into the dayroom, averaging **16.48 FPS**. Five-second averages ranged from 13.2 to 19.0 FPS. The 95th-percentile interval was 85.17 ms and the longest was 178.40 ms. No five-second window reached 25 FPS. The [best earlier run](../4k-prison-depth-and-write-audit) averaged 17.62 FPS on the same route, with a 12.4 FPS five-second minimum and a 75.93 ms 95th percentile. These builds differ in additional CPU-side code and diagnostics. One pass per configuration gives no evidence of a gain in gameplay FPS. [Frame times](escort-frames.csv) · [Metrics](escort-metrics.json)

The reporting window contained 1,960 presents that fell within complete CPU sampling intervals. The submission thread used **35.20 ms of CPU per present**, the six list-recording threads used 140.18 ms combined and the refresh workers used 22.62 ms combined. The older three matched runs used 37.25–40.92 ms on the submission thread. Windows had at least 5.18 GiB of physical RAM available during this escort. [CPU samples](thread-cpu.csv) · [Earlier CPU measurements](../ryzen3700x-thread-cpu-on-three-escorts)

Lucia and the officer reached the end of the route. The officer's arm showed colored patches near the start and nearby figures still rendered as silhouettes in the dayroom. The separate cell interval presented 1,212 frames in two minutes, averaging 10.10 FPS, with a 3.0 FPS five-second minimum and a maximum interval of 943 ms. [Paired images](compared-endpoints.jpg) · [Gate and dayroom](escort-route.jpg) · [Cell data](cell-metrics.json)

The run used a Ryzen 7 3700X, RTX 3090, 32 GiB RAM and SSD. Series X settings and 3840 × 2160 output were retained with no DLSS or frame generation. The renderer included the corrected page publication order, full GPU write declarations and the original indirect light grid.
