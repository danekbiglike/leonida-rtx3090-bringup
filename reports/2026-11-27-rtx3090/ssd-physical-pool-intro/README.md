On 27 November 2026 danekbiglike exercised the file-backed pool in a live 4K Series X run on the RTX 3090 and Ryzen 7 3700X. After an initial saved-game load prompt we selected New Game in an isolated save copy. The process exited during the introduction. The last sampler row was at 10m54.9s. The renderer reported an unhandled access violation writing to address zero. It recorded no process-limit notification. Peak job memory was 30.91 GiB against a 42 GiB limit. System commit headroom stayed above 18.64 GiB across the samples.

The 6,538,919,936-byte temporary file was automatically removed after exit. The test used the streaming profile and did not reach the prison escort. It does not establish whether the SSD pool affects the earlier escort failure. A separate candidate was compiled in part of this session. Treat FPS and paging in the introduction as uncontrolled.
